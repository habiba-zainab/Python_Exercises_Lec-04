## 📚 Overview
This repository contains my practice work for Lecture 04, focusing on working with dictionaries and sets to organize, map, and manipulate complex data structures in Python, and a Shopping Cart & Inventory project.

## 📖 Topics Covered

### ✅ Dictionary Basics
* Dictionary creation and key-value pairs
* Accessing values using keys
* Adding, updating, and modifying items
* Neested dictionaries
* Dictionary mutability

### ✅ Dictionary Methods
* **Extracting data:**  `keys()`, `values()`, `items()`
* **Safe value access:**  `get()`
* **Modifying dictionaries:**  `update()`, `pop()`, `popitem()`, `clear()`
* Copying dictionaries

### ✅ Set Basics
* Set creation and uniqueness of elements
* Unordered nature and immutability of set items
* Creating empty sets (`set()`)
* Duplicate elimination
